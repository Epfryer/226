---
name: Experience modernization priorities
description: Preserve the portfolio's behavior while bringing desktop and mobile quality to parity.
---

Modernization must preserve how the site currently functions, including the flipbook. Desktop and mobile should be equally capable and polished; optional new ideas should be presented separately.

**Why:** The user explicitly requested improvements without changing existing functionality and emphasized desktop/mobile parity.

**How to apply:** Prioritize compatibility, reliability and usability over newest-version upgrades or redesigns. Keep optional new experiences outside maintenance scope unless approved.

The user approved projects opening independently and remaining open while scrolling. Expanded work should flow across the page rather than sit in a single-image bounding box; project facts belong left of the first image and the description to its right.

**Why:** The user explicitly confirmed the open/scroll behavior was right, then corrected the contained gallery and stacked text layout using an annotated screenshot.

**How to apply:** Preserve independent open states and gallery positions. Keep facts, artwork, and description in the same horizontal flow when refining the project feed.

The Projects view intentionally uses compact navigation instead of the permanent desktop sidebar; do not extend that change to other pages without a request.

**Why:** The user wants opened artwork to occupy the available page like their BIG reference, with navigation no longer consuming the left side.

**How to apply:** Preserve the larger in-page artwork and compact hover/click/keyboard navigation on Projects while retaining other pages' navigation.
