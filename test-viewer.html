PDF Viewer Enhancements Test Page

What's New

Desktop click-to-flip: Left 40% → Previous, Right 60% → Next
Glass backdrop with blur effect
Double-click/tap to toggle zoom (fit ↔ 2x)
Landscape mode: Title hidden, only X button shows
Boundless pan - content can extend past edges
Better Safari touch gesture handling

How to Test

Desktop:

  • Click left side (40%) to go to previous page
  • Click right side (60%) to go to next page
  • Double-click to toggle zoom (fit ↔ 2x)
  • Use Ctrl/⌘ + scroll to zoom with mouse
  • Notice the glass blur effect on the backdrop

Mobile/Tablet:

  • Rotate to landscape - title bar hides, only X button shows
  • Pinch to zoom in/out
  • Double-tap to toggle zoom
  • Pan beyond screen edges when zoomed

Note: The PDF viewer needs to be accessed through the main application at /publications. This test page demonstrates the features but requires the full React app to function.
