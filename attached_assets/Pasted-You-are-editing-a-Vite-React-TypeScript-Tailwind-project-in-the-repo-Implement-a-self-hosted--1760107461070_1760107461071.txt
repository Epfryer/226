You are editing a Vite + React + TypeScript + Tailwind project in the repo. Implement a self-hosted Publications page that lists PDFs as covers and, on click, animates a smooth zoom-in to a full-screen PDF viewer using PDF.js. Do everything below precisely:

## Goals & UX

* New route `/publications`.
* Grid of publication cards (cover image, title, year). Covers should be derived from either a provided JPG/PNG in `/publications` or the first page of the PDF if a cover image isn’t provided (fallback thumbnail rendering can be “coming soon”).
* Click a card → **beautiful motion** that:

  * Zooms the card to a full-screen modal using Framer Motion `layoutId`.
  * Fades in a dimmed backdrop.
  * Inside the modal, load a **self-hosted** PDF.js **stock viewer** via `<iframe>` (not just canvas rendering), with a direct “Download PDF” link under it.
* Modal supports:

  * ESC to close, click backdrop to close.
  * Deep linkable query `?doc=<slug>` so `/publications?doc=my-portfolio` opens directly into the viewer.
* Fully responsive; grid uses Tailwind; modal is full-bleed on mobile.

## Tech decisions

* Self-host **pdfjs-dist** stock viewer files under `/public/pdfjs` so the iframe src is `/pdfjs/viewer.html?file=%2Fpublications/<file>.pdf`.
* Use **Framer Motion** for motion (already compatible with Tailwind).
* Use a small typed data file `src/data/publications.ts` to list your PDFs (title, year, slug, pdfPath, coverPath?).

## Copy PDF.js viewer to /public

Create a tiny prepare step to copy the viewer on install, and commit the copied files:

* Add a Node script `scripts/copy-pdfjs.js` that copies:

  * `node_modules/pdfjs-dist/web/**` → `public/pdfjs/`
  * `node_modules/pdfjs-dist/build/pdf.worker.min.js` → `public/pdfjs/build/pdf.worker.min.js`

* Add to `package.json`:

```json
{
  "scripts": {
    "prepare": "node scripts/copy-pdfjs.js"
  }
}
```

* Run `npm run prepare` so the files land in `public/pdfjs`.
* Ensure the repo contains `public/pdfjs/**` after copying (we are committing them so hosting stays self-contained).

## Notes & pitfalls to handle

* Vite will serve anything under `/public` at the root. Keep viewer paths relative to `/pdfjs/...`.
* Ensure the **worker** is available to the viewer: it expects `/pdfjs/build/pdf.worker.min.js`. Place it there.
* Some hosts require `Accept-Ranges: bytes` for partial PDF loading; this is usually on by default. If PDFs don’t stream, still ensure the viewer loads fully.
* If you later want thumbnails from the PDF (instead of manual covers), we can add an async thumbnailer using `pdfjs-dist` in a web worker; for now, an image cover is fine.
